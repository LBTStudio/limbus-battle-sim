# リンバスTRPG 戦闘ルール抽出メモ（PDF p.25–52, 302–312）
出典: `source/新リンバスTRPG.pdf`（PDFページ番号＝本文ページ番号）

## 1. 戦闘の流れ / 速度と行動順
- 流れ(p25): ①戦闘フィールド準備 ②速度ダイス ③行動選択 ④大罪管理 ⑤速度順に行動(対象選択→スキル処理→ダメージ処理) ⑥継続/終了確認 ⑦戦闘後処理
- 速度(p27): キャラシートの速度(例: 1d6)を各R毎にロール。最終値0以下なら1、13以上なら12に丸め。対応する速度マスにコマ配置。
- 行動順(p30): 速度が高い順。同速度は**敵陣営が先**、味方同士は自由に決定。
- 手番でできること: **ディレイ** / **戦術スキル使用**。
  - ディレイ(味方のみ): 敵が他の味方を対象にスキル使用する時、1回だけ対象を自分に変更して応戦可。未使用なら手番終了後に改めてスキル使用可。使用権はディレイ順。
- 戦術スキル選択(p28): **2b4** を振り、出目に対応するランク(1〜4)から選ぶ。**スキル0は出目に関わらず常時選択可**。E.G.Oは出目無関係で選択可。
- スキルは1Rに基本1つのみ使用可(使用で消費、p37)。

## 2. スキル分類 (p31–36)
- 攻撃スキル: 斬撃/貫通/打撃の攻撃属性。
- 守備スキル: 防御/回避/反撃 + 特殊な**マッチ可能反撃/マッチ可能防御**。
- マッチ可否は**受け側が決める**(マッチするか一方攻撃として受けるか)。攻撃側は指定不可。

## 3. ダイスとマッチ(相剋)の解決 (p32–33)
- マッチ: **一番上（先頭）のダイス同士**をロールし出目(ダイス威力)を比較。
  - 小さい方のダイスは**破壊**。同値なら両方生き残り。
  - 繰り返し(内のダイスに進む)、どちらかのダイスが全滅したらマッチ終了。
  - **勝者**: 残った(破壊されず残った)ダイスを順にロールし、その出目がダメージ(それぞれ耐性補正適用)。
  - **敗者**: 敗北後、残った破壊不能ダイスでのみ攻撃できる(p33)。
- 一方攻撃(守備しない側): 攻撃側ダイスをロールし出目=ダメージ。
- 防御(p34): 双方のダイスを順に振り、**攻撃出目−防御出目**がダメージ。負値でも回復しない(0扱い)。
- 回避(p34): 回避出目が上回れば攻撃ダイス破壊(破壊不能も強制破壊)。同値で双方破壊。攻撃が上回れば攻撃出目=ダメージで回避ダイス破壊。終了時残回避ダイスは破壊。
- 反撃(p34, 47): 一方攻撃を受けた時、反撃ダイスをロールし出目=ダメージ(攻撃属性を持つ→耐性適用)。
- 相殺(p35): 守備スキルを対象にスキルを合わせると双方の守備スキルが無条件除去(使用時効果なし)。
- 破壊不能ダイス(p33): マッチで負けた場合マッチから除去され d値=1 に固定。敗北側は攻撃後に残った破壊不能ダイスで攻撃。マッチ可能防御が勝つと破壊不能の効果を無効化(p36)。
- マッチ可能防御(p35–36): 勝利→残ダイス分**SANダメージ**(SAN所持なし/0なら威力の半分をHPに)。敗北→全ダイスd値1固定で通常防御。マッチ可能反撃(p35): 攻撃スキル同様マッチして攻撃可(耐性適用)。

## 4. ダメージ処理 (p38–39)
- 耐性補正(ダイス毎に適用): **脆弱=2倍 / 弱点=+5 / 普通=±0 / 抵抗=−5 / 耐性=−10 / 免疫=0**(多値系ではなく固定値)。
- 補正順序: 加算減算→乗算除算。小数は切捨て。
- 確定ダメージは**HPとSAN両方**に適用。HP0で死亡(p39)。
- 感情レベル(p41): 3R LV1=戦術選択3b4 / 5R LV2=マッチ勝利ダメージ+2 / 7R LV3=全ダメージ+1 / 9R LV4=最強耐性1つ一段階低下 / 11R LV5=最弱耐性1つ一段階低下。

## 5. 大罪 (p29, 42)
- 大罪共鳴: 使用中スキルの大罪共鳴数が2以上なら スキル威力+(共鳴数−1, 最大3)。
- 大罪資源: R終了時に使用スキル分蓄積、E.G.O使用の消費に充当。
- E.G.O SANコスト(p42): ZAYIN 10 / TETH 15 / HE 25 / WAW 35 / ALEPH 45。
- E.G.O侵蝕判定(p43): 士気低下(SAN最大値25%以下)になったら 1d100 ≤ SAN×4 で覚醒、超えると侵蝕(SAN0なら確定侵蝕)。侵蝕中は必ず攻撃、多くは[敵味方識別不可]。
- オーバークロック(p44): SAN消費+10・大罪資源×1.5で侵蝕スキルを通常攻撃として使える。
- [同化](p45): HP/SAN/耐性/スキル0/パッシブ継承し新戦術スキル3R継続。[影響](p45): 行動不能と引き換えに戦闘開始時効果。

## 6. SANと精神 (p39, 43, 345)
- ダメージは常にHP+SAN両方に適用。
- 士気低下: SAN≤25%。精神の種類(p345)の士気低下効果が永続(SAN回復まで)。
- 混乱: SAN=0。次のRのR終了時まで。混乱中は精神の混乱効果(例: パニック=行動不能&全耐性脆弱)。終了時にSAN全回復。E.G.Oは選択不可(p44)。
- E.G.Oコスト注記: 危険度ランク分SANは即時減少。

## 7. 広域攻撃/複数行動 (p46–47)
- 広域攻撃: **メインターゲット1名**(マッチは必ずメインと) + **サブターゲット=広域指定人数−1名をランダム**。サブには同時攻撃(守備はマッチ可能以外のスキルで対応可)。
- 複数回行動のボス: 対象スキルを指定可能。スキル使用後の「空きスロット」へは一方攻撃可能。

## 8. 戦闘用語(タイミング/位置) (p48–51)
- タイミングは表の上から順に優先(p48)。
- 的中時系: 最大値/最小値/(最大+最小)/2以上=過半数/未半数に判定 (d値1では発動しない)。
- クリティカル = **呼吸判定**。呼吸バフ(p304): 攻撃前、呼吸数×5%でクリティカル攻撃→全ダイス+2、ダイス数×3だけ呼吸減少、R終了時1減少。
- 位置関係(p51): 自分/対象/両隣/前方(より速い側)/後方(より遅い側)/攻撃者/全てのキャラクター等。速度マスを基準に前後関係。

## 9. 主なバフ・デバフ (p302–312)
- バフ: **パワー**(攻撃威力+数) / **忍耐**(守備威力+数) / **クイック**(速度+数) / **保護**(被HPダメージ−数) / **混乱保護**(被SANダメージ−数) / **ダメージ量増加+数** / **d値強化** / **呼吸**(クリティカル) / 大罪別・属性別威力/ダメージ増加。
- デバフ: **虚弱**(攻撃威力−数) / **武装解除**(守備威力−数) / **束縛**(速度−数) / **脆弱**(被HPダメ+数) / **混乱脆弱**(被SANダメ+数) / **ダメージ量減少−数** / **麻痺**(全ダイスd値−数÷2, 1なら1) / 出血(攻撃ロール時HPダメ) / 恐慌(攻撃ロール時SANダメ) / 火傷(R終了時HP) / **沈潜**(R終了時SAN、SANなしはHP) / 破裂(HP)/振動(SAN)のバースト系 / 毒。
- 中立バフ: **挑発値**(p311): 対象選択時、挑発値×5%で自分が選ばれる(ターゲット指定の例外)。**バリア**(被ダメージカット、カット分消費)。
- バフ記法: 数値(最大10等)、持続[1R]、表記なしなら戦闘終了まで(p302)。

## 10. 表記その他
- ダイス表記: 1d6, 2d8, 2b4 (b=シミュブーム/選択), 速度例 1d7+1。
- ランダム値(p37): 最小〜最大を満たすコマンドに変換 (5~10→1d6+4)。
